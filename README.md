# CH-TradeLock

로어에 **"거래불가"** 가 들어간 아이템을 거래 / 유출 / 사망 손실로부터 보호하는 Paper 플러그인입니다.
(구 이름: IsakLackitem)

- 서버: Paper 1.21+ / Java 21
- 선택 플러그인: AxTrade (거래 GUI 차단에 활용)

## 기능

| 기능 | 설명 |
|---|---|
| 드롭 차단 | 거래불가 아이템은 버릴 수 없습니다. |
| 줍기 차단 | 거래불가 아이템은 바닥에서 주울 수 없습니다. |
| 이동 차단 | 상자 등 다른 인벤토리로 옮길 수 없습니다. (클릭 / 쉬프트클릭 / 드래그 / 숫자키 / F키 포함) |
| 명령어 차단 | 거래불가 아이템을 손에 들고 있으면 `blocked-commands` 의 명령어를 쓸 수 없습니다. |
| **사망 시 보호** | 사망해도 거래불가 아이템은 떨어지지 않고, 리스폰 후 인벤토리로 돌아옵니다. |
| **보호 월드** | `death-protection.protected-worlds` 에 적은 월드에서 죽으면 인벤토리와 경험치를 모두 유지합니다. |
| **인벤세이브권** | 지정한 아이템을 인벤토리에 가지고 죽으면 인벤토리와 경험치를 유지하고 티켓을 1개 소모합니다. |

- 거래불가 판별: 아이템 로어의 한 줄에라도 `거래불가` 가 들어 있으면 거래불가 아이템입니다.
- 인벤토리를 열지 않은 상태에서 F키(양손 바꾸기)로 왼손에 드는 것은 허용됩니다.
- 상자 등을 연 상태에서 F키로 넣는 것은 막습니다.
- `whitelisted-guis` 에 GUI 제목(부분 일치)을 넣으면 그 GUI에서는 이동을 허용합니다.
- 사망 시 보호는 리스폰 후 **원래 슬롯이 아니라 빈 칸**에 들어옵니다. (Paper 기본 동작)

## 명령어 / 권한

| 명령어 | 설명 | 권한 |
|---|---|---|
| `/tradelock reload` | 설정(config.yml) 리로드 | `chtradelock.admin` (기본 OP) |
| `/invsave set` (별칭 `/인벤세이브권`) | 손에 든 아이템을 인벤세이브권으로 지정 | `chtradelock.admin` |
| `/invsave clear` | 인벤세이브권 지정 해제 | `chtradelock.admin` |
| `/invsave give [수량]` | 인벤세이브권 지급 (기본 1개) | `chtradelock.admin` |

## 설정 (config.yml)

```yaml
# 이 문자열이 GUI 제목에 들어 있으면 거래불가 아이템 이동 허용 (부분 일치)
whitelisted-guis:
  - "예시 GUI"

# 거래불가 아이템을 손에 들고 있을 때 차단할 명령어 (슬래시 없이, 대소문자 구분 없음)
blocked-commands:
  - "ah"
```

## 사망 보호 (보호 월드 / 인벤세이브권)

구 `인벤세이브권.sk` 스크립트를 플러그인으로 옮긴 기능입니다. 사망 처리는 한 곳에서 **보호 월드 -> 인벤세이브권 -> 거래불가 아이템만 보호** 순서로 처리해서 아이템이 복사되거나 사라지지 않습니다.

```yaml
death-protection:
  protected-worlds: ["dun", "tuto", "boss"]   # 이 월드에서 죽으면 인벤토리/경험치 유지
  consume-ticket: true                         # false 면 가지고만 있어도 계속 보호 (소모 X)
  ticket-item: null                            # /invsave set 으로 저장
```

- 인벤세이브권 판별은 **이름 / 로어 / 재질 / NBT 가 같은 아이템**입니다. (수량은 무관)
- 다른 플러그인이나 게임룰이 이미 인벤토리 유지를 켠 사망에서는 티켓을 소모하지 않습니다.
- 인벤세이브권 사용 시 / 보호 월드에서 죽었을 때 채팅으로 안내합니다.

### 스크립트(인벤세이브권.sk)에서 옮길 때
1. 인벤토리에 기존 인벤세이브권을 들고 `/invsave set` (기존 아이템과 똑같이 지정해야 이미 가진 티켓이 인식됩니다)
2. 스크립트의 사망 처리와 `/인벤세이브권지정` 등 명령어는 제거하세요. (남겨 두어도 플러그인이 중복 소모하지 않지만 정리하는 것을 권장합니다)
3. `menu.sk` 등 다른 스크립트가 쓰는 `초심자남은초()` 함수는 그대로 남겨 두세요.

## 빌드

JDK 21 + Maven 이 필요합니다.

```
mvn package
```

`target/CH-TradeLock.jar` 를 서버 `plugins/` 폴더에 넣으세요.

## 이전(IsakLackitem)에서 옮길 때

- 설정 폴더가 `plugins/IsakLackitem` -> `plugins/CH-TradeLock` 으로 바뀝니다. 기존 `config.yml` 내용을 복사해 주세요.
- 명령어가 `/isakLackitem reload` -> `/tradelock reload`, 권한이 `isakLackitem.admin` -> `chtradelock.admin` 으로 바뀌었습니다.
- 기존 `IsakLackitem.jar` 는 삭제하고 새 jar 만 넣으세요.
